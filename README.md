# N2 桌面（OemLauncher）

一个可以设为默认主屏的 Wear OS 启动器，配一个在手机上编辑布局的配套 App。手表端（`wear/`）负责在手腕上运行：蜂窝、网格、列表三种布局，常用应用固定在中心，没有手机也能完成全部基础设置。手机端（`mobile/`）负责编辑：排序、常用、隐藏、替换图标、外观调整，并提供与手表真实分辨率一致的圆屏预览，连上手表后同步。两端共用 `shared/` 里的模型、配置编辑、排序规则、同步协议与蜂窝几何算法，所以预览与手表上看到的是同一套计算。

## 为什么比同类更好

以下每一点都对应仓库里的实际实现：

- **预览与手表同源**：手机预览直接调用 `shared` 的螺旋、鱼眼、投影、边界与圆屏裁剪算法，按目录里手表的真实分辨率与密度绘制，不是按手机比例缩放的示意图。
- **没有手表也能用**：内置 40 个示例应用的演示模式，加上离线草稿自动保存与撤销/重做，买表前或未配对时也能把整套布局调好。
- **同步不是黑盒**：同步诊断页按节点显示能力状态、最近收到 catalog/state 的时间、上次发送的修订号与结果、缺失图标清单，以及最近一次 API 错误（按状态码映射成本地化短语，不记录消息与节点名）。
- **冲突处理是显式的**：按修订号最大者胜（LWW），手表上有更新修改时手机不会悄悄覆盖，而是让你选择“载入手表配置”或“用我的修改覆盖”。
- **图标按内容寻址**：`IconId` 是图标字节的 SHA-256 摘要前 24 位十六进制；同一个图标只存一份、只传一次，重复导入同一图标包不会累积文件。
- **导入有安全边界**：ZIP 图标包限制 500 个条目、单文件 2 MB、总量 50 MB，非图片内容与不安全路径一律拒绝；应用前先给出匹配预览，确认后才落盘，且整个过程可撤销。
- **中文用户优先**：两端都有完整的中英文界面，跟随系统语言；手机端搜索支持拼音全拼与首字母（`dh`/`dianhua` 搜到电话、`lxr`/`lianxiren` 搜到联系人，多音字的所有读音都会建索引），演示数据也跟随应用语言生成中文示例应用。
- **无障碍可用**：编辑器每行提供自定义无障碍操作（上移、下移、隐藏、换图标），触控目标不小于 48dp；手表蜂窝用最近中心命中，点击区域不重叠，且每个可见图标都有独立的语义节点供 TalkBack 逐个访问。

## 功能清单

### 手表端（`wear/`）

- 三种布局：蜂窝（鱼眼缩放、拖动、惯性、橡皮筋回弹、吸附居中）、网格（三列，图标保持正圆，长名称按单词换行）、列表（`TransformingLazyColumn`，边缘条目缩小淡出）。
- 常用应用最多 7 个，固定在蜂窝中心与第一圈；支持排序（自定义/字母/最常用/最近使用）、隐藏与恢复。
- 长按菜单：切换常用、隐藏、打开系统应用信息。
- 表冠旋转与触觉反馈（蜂窝逐格居中，网格与列表滚动）。
- 设置入口不遮挡内容：蜂窝在底部信息带（图标进入前淡出），网格与列表作为内容最后一项。
- 独立可用：`com.google.android.wearable.standalone = true`，不依赖手机；本地编辑同样走修订号提交并发布回执。
- 入口三选一：HOME intent-filter 可尝试设为默认主屏，另外提供常用应用 Tile 与普通应用图标入口。
- 常用应用 Tile：2×2 居中布局，显示前 4 个常用（图标 + 名称），点击直启，无常用时显示空状态与“打开启动器”按钮，配置变化后自动刷新。
- 同步状态可见：设置页显示连接状态、按本地时间格式化的上次同步时间与最近一次同步结果。

### 手机端（`mobile/`）

- 首页：预览缩略图（点击进入全屏预览）、紧凑的连接与同步状态区、四个入口（布局编辑、外观、图标、帮助）。
- 布局编辑器：搜索（支持中文名、拼音全拼与首字母，多音字全部读音都会建索引）、排序模式、常用星标、拖拽排序、行尾溢出菜单（上移/下移/隐藏/换图标）、隐藏应用列表、撤销/重做、自动保存。
- 预览：与手表同尺寸的圆屏预览，可拖动探索，支持蜂窝/网格/列表三种模式与“居中”复位。
- 外观：布局模式、图标大小、图标形状、鱼眼强度、网格列数、标签开关、吸附、触觉、减弱动画。
- 图标：从相册选图并裁剪（输出 192 px PNG，圆形或方形），或导入 ZIP 图标包（支持包名图片与 `appfilter.xml` 组件映射），导入结果先预览再应用，可恢复默认。
- 同步与诊断：同步卡片显示阶段与冲突处理；同步诊断页提供“重新请求目录”与“重新发送”。
- 界面语言：跟随系统语言显示中文或英文；Android 13 及以上可在“设置 → 系统 → 语言 → 应用语言”里单独设置本应用的语言。演示模式的示例应用名与图标会跟随应用语言重新生成。

### 同步（`shared/protocol` + 两端 `sync/`）

- 三条数据项：手表发布 `catalog`（目录 + 默认图标），手机发布 `config/desired`（配置 + 自定义图标 + 修订号），手表发布 `config/state`（当前配置与处理结果，兼作回执）；另有一条 `request-catalog` 消息让手机主动拉取目录。
- 负载 gzip 压缩，单个 DataItem 上限 90 KB，解压后上限 2 MB；图标随内容寻址只传一次。
- 目录与 state 都按内容摘要去重；目录发布有 10 秒节流，`request-catalog` 消息不受节流限制。
- 修订号单调递增（LWW），拒绝回执会带上手机正在等待的修订号（`SyncKeys.REVISION`，可选键，兼容旧版手机）。
- 所有 Data Layer 调用都捕获 `ApiException` 并降级为“未连接”，不崩溃。

## 快速开始

### 环境要求

- JDK 17 或更高（`compileOptions` 目标为 Java 17；本仓库在 Temurin 21 上构建验证）。
- Android SDK：`compileSdk = 37`、`targetSdk = 36`；手表端 `minSdk = 30`，手机端 `minSdk = 26`。
- Gradle 由 wrapper 提供（Gradle 9.8.1），无需单独安装。
- 如果 Gradle 提示找不到 SDK，在仓库根目录新建 `local.properties`，写入 `sdk.dir=<你的 SDK 路径>`（该文件已被 git 忽略）。

### 第三方依赖

除 AndroidX / Compose / Wear 官方库外，手机端只引入了一个第三方库：

- `com.belerweb:pinyin4j:2.5.1`：把中文应用名转成拼音，供搜索框的全拼与首字母匹配使用。它的词典在首次调用时加载，因此调用点必须在 IO / Default 线程（见 `mobile/.../search/PinyinRomanizer.kt`）。

版本统一声明在 `gradle/libs.versions.toml`。

### 构建命令

在仓库根目录执行（Windows PowerShell）：

```powershell
# 单元测试 + 两端调试包
.\gradlew.bat :shared:test :wear:testDebugUnitTest :mobile:testDebugUnitTest assembleDebug

# Lint
.\gradlew.bat :wear:lintDebug :mobile:lintDebug

# Release（开启 R8 与资源压缩）
.\gradlew.bat assembleRelease
```

### 安装命令

```powershell
adb -s <手表序列号> install -r wear\build\outputs\apk\debug\wear-debug.apk
adb -s <手机序列号> install -r mobile\build\outputs\apk\debug\mobile-debug.apk
```

两端 `applicationId` 都是 `com.n2.oemlauncher`，安装后按 `docs/delivery.md` 的“安装与使用”一节完成主屏设置、Tile 添加与配对。
