# N2 设计语言：摩卡玻璃

手机和手表共用的视觉规范。参考图是第三方作品，只留在本地 `reference/`，不随仓库发布；决策背景见 `docs/decisions.md` 的 D2、D4。颜色和材质参数以代码为准：`shared/src/main/kotlin/com/n2/oemlauncher/shared/design/`。本文和代码不一致时，先改代码，再改本文。

## 1. 气质

温暖、安静、贵重。像一杯拿铁旁边的一块磨砂玻璃：深咖啡色打底，玻璃把内容托起来，香槟色只留给“被选中的那一个”。

三条克制原则：

1. **一屏只有一个主角**。香槟色实心填充同一屏最多出现一处大面积使用（主按钮、当前选中项），其余都是玻璃。
2. **模糊只为分层，不为炫技**。只有浮层出现、或内容从玻璃下面滚过时才做实时模糊。
3. **层次靠光，不靠线**。玻璃靠顶部边缘的柔光和底下的投影立起来，不画描边，不画分割线。

## 2. 颜色

两套配色角色完全一样。手表永远用 Mocha；手机跟随系统，深色用 Mocha，浅色用 Latte。**不跟随壁纸取色。**

| 角色 | Mocha | Latte | 用途 |
| --- | --- | --- | --- |
| `background` | `#140E0B` | `#F3EBE2` | 页面底色 |
| `backgroundGlow` | `#3A2818` | `#E8D6C3` | 暖光晕，只以径向渐变出现 |
| `coolGlow` | `#2B3446` | `#D5DCE8` | 冷光晕，低透明度，与暖光晕形成对比 |
| `glass` | `#302620` · 65% | 白 · 70% | 行、卡片、未选中的控件 |
| `glassStrong` | `#51463F` · 80% | 白 · 90% | 玻璃上的玻璃（玻璃卡片里的按钮） |
| `rimLight` | `#FFF3E6` · 22% | 白 · 80% | 玻璃顶部边缘柔光 |
| `accent` | `#D6BFA8` | `#D2B79C` | 香槟：选中、主操作 |
| `accentLight` / `accentDeep` | `#E6D2BE` / `#BEA591` | `#E3CDB6` / `#B89B80` | 香槟渐变的上下两端 |
| `onAccent` | `#2E1D0D` | `#2E1D0D` | 香槟上的文字和图标 |
| `accentText` | `#BEA591` | `#7E624A` | 香槟色文字（分组标题）；浅色下必须更深才够对比度 |
| `textPrimary` | `#FFF7EE` | `#2A1D14` | 标题、正文 |
| `textSecondary` | `#D9CCC0` | `#5E4E43` | 说明、数值 |
| `textTertiary` | `#A8998C` | `#857467` | 提示、禁用（只到 3:1，不能用于正文） |
| `highlight` | `#F8BA63` | `#B86A1F` | 杏橙：焦点圆点、进度，不超过 8dp |
| `positive` / `negative` | `#B9C98A` / `#E8846B` | `#5E7335` / `#A9482F` | 已连接、成功 / 错误 |

对比度由 `shared` 的 `PaletteContrastTest` 自动检查：正文 ≥ 4.5:1，提示和指示 ≥ 3:1（玻璃按透明度叠到底色上再算）。

## 3. 材质：玻璃

一块玻璃从下到上分五层：

1. 底色 `background`；
2. 环境光：暖光晕 + 冷光晕，静态径向渐变；
3. 玻璃面：`glass` 半透明填充；
4. 边缘柔光：`rimLight` 1dp 描边，从顶部向下渐隐，到高度的 55% 消失；
5. 投影：抬起的玻璃底下一层很软的影子（可选）。

三种规格（`GlassSpecs`）：

| 参数 | 手表·精致 | 手表·轻量 | 手机 |
| --- | --- | --- | --- |
| 浮层下内容的实时模糊 | 12dp | 无，改用 70% 暗幕 | 24dp |
| 环境光 | 有 | 无，纯 `background` | 有 |
| 边缘柔光 | 1dp | 1dp | 1dp |
| 投影 | 35% | 无 | 28% |
| 过渡动画 | 有 | 无 | 有 |

什么时候做实时模糊：

- 手表：只在浮层出现时（布局切换器、长按菜单、确认框），对**静止**的下层内容模糊一次。
- 手机：底部弹层和对话框模糊它们下面的整页内容；Android 12 以下改用不透明的 `glassStrong`。
- 卡片和行本身不做实时模糊——它们下面只有静态的环境光，画半透明玻璃的效果和真模糊看不出区别。

禁止：滚动过程中的实时模糊；列表每一行各自模糊；玻璃叠玻璃超过两层。

手机端的玻璃是“液态玻璃”（`mobile/.../ui/components/GlassSurface.kt`，基于 Backdrop 库）：

- 卡片、首页方块和浮层折射它背后的东西：边缘一圈把背景压缩、带一点色散，中间保持原样；不做模糊（背后只有静态光，模糊看不出来）。胶囊、轨道和列表行不折射：它们的折射带只有几个像素，却要多编译一个着色器（第 9 节）。
- 镜面高光沿 45° 方向落在两个相对的角上，是一条渐变描边（`SpecularRim`），不用库自带的着色器高光；深色下高光约为 `rimLight` 的两倍亮度。
- 色调上浅下深，上方透出更多背景。
- 页面背景在暖、冷光晕之外加几块边缘清楚的柔和光斑，玻璃边缘折射的正是它们。
- 卡片会把自己导出为背景，卡片上的分段按钮、滑块折射卡片。
- 底部弹层和对话框画在页面自己的窗口里（`GlassOverlayHost`），不开新窗口：整页内容另录一层，浮层模糊并折射这一层。
- 折射需要 Android 13+；更低版本只画表面、高光和投影。
- 手表端不用：手表没有这些效果的预算（第 9 节）。

## 4. 形状

| 形状 | 用在哪 |
| --- | --- |
| 胶囊（全圆角） | 按钮、芯片、搜索框、手表设置行、列表行 |
| 圆角方块 | 手机卡片 28dp、入口方块 24dp、小组件 20dp |
| 圆 | 应用图标、圆形按钮、开关圆点 |
| 饼干（9 个波浪，深度 9%） | **唯一的签名形状**：手表中心的设置齿轮，以及手机预览里的同一个齿轮。其他地方不用 |

饼干轮廓由 `CookieOutline.points()` 生成，两端用同一份点，构造时建好 Path，绘制时不再分配。

不用：直角卡片、细描边卡片、浓重的悬浮阴影。

## 5. 文字

用系统字体（手机多为 Google Sans / Roboto，三星手表为 SamsungOne），不打包字体。中文不用斜体，行高不低于 1.4 倍。

| 层级 | 手机 | 手表 | 字重 |
| --- | --- | --- | --- |
| 大标题 | 28sp / 34 | — | 500 |
| 标题 | 20sp / 26 | 16sp | 500 |
| 小标题 | 16sp / 22 | 14sp | 500 |
| 正文 | 15sp / 22 | 14sp | 400 |
| 标签 | 13sp / 18 | 13sp | 500 |
| 说明 | 12sp / 16 | 12sp | 400 |
| 分组标题 | 12sp，字距 0.06em，`accentText` | 12sp，`accentText` | 600 |

手表最小 12sp。数字用等宽数字（`tnum`），避免跳动。

## 6. 图标

- **界面图标**：Material 圆角线条风格（Compose `Icons.Rounded` / `Icons.Outlined`，优先线条型）。手机 22dp，手表 20dp。玻璃上用 `textPrimary`，香槟上用 `onAccent`。
- **应用图标**（`LayoutSettings.iconStyle`）：
  - 原色（默认）：圆形裁切，外加一圈 1dp 的 `rimLight` 细环，让图标像嵌在玻璃里。
  - 摩卡图标（方案 B，内置在手表里）：低饱和大地色圆盘 + 奶白线条图标（Material Symbols Rounded，Apache-2.0）。圆盘颜色按含义选，共七种：灰蓝、橄榄绿、赭石、陶土红、梅子紫、墨绿、陶土棕；圆盘上半有一层很淡的光泽。数据在 `shared/design/MochaIcons.kt` 和 `MochaGlyph.kt`，手表和手机预览共用。
    - 每个应用按顺序取图标：自定义图标 → 图标包里的绘制图标 → 应用自带的单色图层（画在按原图标主色挑的大地色圆盘上）→ 原色图标。图标包优先于单色图层，因为包里的线条粗细和色调统一。
    - 品牌应用（微信、QQ、支付宝等）用表示用途的通用图标，不画商标。
    - 图标包没收录、也没有单色图层的应用显示原色图标。
- **常用应用**：手表蜂窝里是 1.5dp 的香槟外环；手机列表里是实心香槟星。

## 7. 组件

### 手表

- **背景**：精致档是 `background` 加中心偏上的暖光晕（半径约 70% 屏宽）、右下的冷光晕和边缘暗角；轻量档是纯 `background`。
- **中心设置齿轮**：饼干形香槟实心（精致档 `accentLight` → `accentDeep` 竖向渐变，轻量档用实色 `accent`），中间是 `onAccent` 齿轮，占直径 50%。按下缩到 94%。
- **焦点名称**：沿屏幕底部圆弧，13sp，`textSecondary`；“显示名称”关闭时不画。名称后面不加底带，靠两件事保证可读：名称先描一圈 3dp、90% 不透明的 `background` 色描边再填字；滚进底部名称区（屏幕半径的 20%）的蜂窝格按进入程度平滑淡到 30%。数值和算法在 `shared/design/LabelZone.kt`，手表和手机预览共用。精致档、轻量档都这样做。
- **设置页**：香槟小字分组标题 + 52dp 高的玻璃胶囊行（左图标、中标题、右数值）。开关打开是香槟轨道 + `onAccent` 圆点，关闭是 `glassStrong` 轨道 + `textTertiary` 圆点。滑块是香槟填充 + `glassStrong` 轨道。单选页的选中项是香槟胶囊并带勾。“完成”是底部香槟胶囊按钮。
- **布局切换器**：下层内容模糊（轻量档为暗幕），三个 64dp 圆形玻璃按钮，当前项为香槟。
- **应用菜单页**：图标 + 名称，下面是玻璃胶囊动作行，“隐藏”等破坏性操作的图标用 `negative`。
- **网格 / 列表**：网格图标直接放在背景上，名称用 `textPrimary`；列表每行是玻璃胶囊。靠近上下边缘的行缩小、变淡（现有 `RoundEdge` 算法）。
- **Tile**：ProtoLayout 不支持模糊，玻璃用叠好的实色（`ColorMath.compositeOver`），按钮用香槟。

### 手机

- **背景**：`background` + 左上暖光晕 + 右侧冷光晕，静态，不随滚动移动。
- **顶栏**：透明；内容滚上来后变成 `glassStrong` 玻璃（不做实时模糊）。
- **首页**：
  - 主角是手表预览：圆屏放在一块大玻璃卡片里，卡片外有一圈很淡的香槟光晕（参考图里手机外框的那种）。
  - 连接状态是胶囊芯片（已连接时前面有 `positive` 圆点）。
  - 四个入口是 2×2 圆角方块，玻璃材质，图标 + 标题 + 一行说明；最常用的“布局编辑”用香槟。
- **编辑器列表**：每行是 20dp 圆角的玻璃行；拖动时抬起（投影 + 放大到 1.02）。
- **开关、滑块、分段按钮**：选中为香槟，三者都能拖。
  - 分段按钮是内凹的玻璃轨道，加一颗滑动的香槟胶囊；文字颜色随胶囊覆盖的程度变化。点一段，胶囊弹过去；按住轨道拖动，胶囊放大 1.1 倍、变成透明透镜跟着手指走，松手后落到最近的一段。
  - 滑块和开关的旋钮是奶白玻璃胶囊，按住时放大到 1.35 倍并变成透明透镜，透出下面的轨道。开关的旋钮可以拖过去，松手时离哪边近就停在哪边。
- **底部弹层**：离屏幕左右和底边各 10dp 的悬浮玻璃面板，34dp 圆角；模糊并折射下面的整页内容，页面压一层 30% 暗幕。顶部有拖动条和一行小标题（比如应用名）；往下拖超过三分之一或快速下滑就关闭，点外面或按返回也关闭。
- **对话框**：同样的玻璃，居中，从 0.9 倍弹出。
- **空状态和错误**：一句话 + 一个胶囊按钮，不用插画。

## 8. 动效

| 名称 | 时长 | 用途 |
| --- | --- | --- |
| 短 | 150ms | 按下、开关 |
| 标准 | 260ms | 页面进出、展开收起 |
| 强调 | 380ms | 浮层出现、模糊渐入 |

- 缓动用 Material 的标准减速曲线；拖动与回弹用弹簧（阻尼 0.8，中等刚度）。
- 手机页面进出（`PageTransitions`，420ms，Material 强调减速曲线）：新页面从右侧 28% 处滑入并淡入，从 0.97 放大到 1；下面的页面向左挪 8% 并淡出。返回时反过来。顶栏标题跟着页面一起滑入、淡入，返回按钮和右侧按钮淡入淡出。
- 手机浮层：底部弹层用弹簧（阻尼 0.82）从底边滑入，260ms 滑出；对话框淡入并从 0.9 倍弹出。
- 手表桌面出现：
  - 窗口在表盘上淡入 120ms。
  - 精致档蜂窝的图标从中心齿轮一圈圈展开（强调 380ms）：离中心越远起步越晚；每个图标从 0.5 倍大小、0.6 倍半径的位置淡入长到原位。
  - 网格和列表用页面进入的效果。
  - 动画要等内容就绪、窗口真正显示后才开始：冷启动时在图标解码完成后播放；从设置返回时不重播。
- 轻量档和“减弱动画”打开时：直接切换，或不超过 120ms 的纯淡入，不做缩放。
- 不做：循环播放的动画、呼吸灯。视差只用在手机页面切换时下面那一页的轻微位移。

## 9. 性能规则

- **手表·精致**：实时模糊只对静止内容做一次；环境光的 Shader 在构造时建好；滚动和动画路径上不分配对象。
- **手表·轻量**：不用 `RenderEffect`、不用渐变、不做过渡动画，只画纯色。
- **手机**：
  - 实时模糊只用于底部弹层和对话框；Android 12 以下退化为不透明玻璃。
  - Backdrop 库给每块玻璃各自编译着色器，而且在主线程上编译。所以折射只留给卡片、方块和浮层，高光用渐变描边，不用着色器。
  - 动画流畅度要用 release 包判断：debug 包里一个页面的首帧要 1 秒以上，页面切换动画会整段被吞掉。
- 两端都遵守 `AGENTS.md` 的性能要求：图片按显示尺寸解码并缓存，主线程不做 IO。

## 10. 无障碍

- 对比度见第 2 节，由测试保证。
- 触控目标不小于 48dp。
- 状态不只靠颜色表达：开关同时有圆点位置变化，选中项带勾。
